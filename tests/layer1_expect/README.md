One file per race: RACE = '<race dir name>', P = 'Pxx' (winner workbook), CHECKS = [(label, lambda I: ...), ...]
using helpers from tests/l1helpers.py (link, strike, move, ratio, same, eqpt, eqr, shared, pset, sky). Labels start with the
claim number in docs/classic/<race>/winner_read.md. Items the read withdrew or the checker corrected follow the corrected version.
Items outside Layer 1's rules are written as 'not listed' checks with the reason in the label.
