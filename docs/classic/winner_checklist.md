# Winner checklist — every kind of detail found in winners so far (handover, 12 Oct 2026)

## How to use this file
1. Read a new race's winner (or blind runner) against each numbered item below; every number here is copied from docs/classic/*/winner_read.md, */blind_test.md and the design notes (checker corrections applied, withdrawn claims marked WITHDRAWN).
2. "Field" gives what the checker found for the rest of the field: ONLY runner / k of n / NOT unique. A detail weighs only when it JOINS the winner's web (Eddie: relationships first; counts do not pick winners — see section 3).
3. Abbreviations: H = horse natal, J = jockey natal, S = race sky, GC = great circle, Flat = flat plane, Equator = |Dec|; "->" = sky body to natal body; "|" separates the two ends of a both-ends strike.

Standing tolerances (layer1_README v1–v1.4): whole ±0.005, ninth ±0.0005 (links, strikes, sky numbers); movement ±0.01 / ±0.0011; Equator values ±0.01 / ±0.0011;
sky/natal ratios p <= 30, q <= 9, not 1, tight <= 0.005% (near to 0.01%); same-body sets <= 0.15%, all three simple; shared pairs <= 0.5%; Equator ratios tight <= 0.01% (near to 0.05%);
pair sets (H:J:S) all simple, 1 allowed, worst <= 0.05%; values < 0.5 skipped; cross link close = RA < 1.5 or Dec < 0.3 (near RA < 2.0 or Dec < 0.6); inside one chart RA < 1.5 or Dec < 0.6;
contacts (sky body close to natal, no number) close RA < 1.5 or Dec < 0.3; h:j ratios tight 0.005%, near 0.02%; pair_family tight 0.005%, near 0.02%. No stars, no Moon. Rahu/Ketu both listed (Layer 2 folds).
