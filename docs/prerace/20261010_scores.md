# Pre-race scores, 10 Oct 2026 — one rule for every race (`tools/prerace_score.py`)
Run on the packs rebuilt with the 10 Oct fixes (Moon on Method 2, number hold windows, same-body chords near the window). A ROUGH guide
(Eddie: "a rough score out of 10"), not a probability. Components (max 8, shown /10):
- **A Sun–Mars across the pair (0–3)**: 3 = one chart's natal Sun and the other chart's natal Mars both tight IN the race (or held through it);
  2 = that cross within off−2 / finish+2 min; 1 = Sun and Mars only in one chart; 0 = none.
- **B tight join in the race (0–2)**: 2 = both sides ≤0.02%, 1 = one side.  **C receivers (0–2)**: tightest (#1) items ≤0.02% in the race,
  both charts, Moon included (1–2 → 1, ≥3 → 2).  **D** both-sides-tight beat near the race (0–1).
- **STANDOUT** = the only pair with A = 3 and the top (or joint-top) score.

**Backtest on the seven known races:** the STANDOUT rule fired twice (Doncaster: Olympe De Gouges / Noonan; Catterick: Wotever Next / Mason) —
both won. It did not fire in the other five. The plain top score held the winner outright in 1 of 7 (3 of 7 counting ties); Carlisle's and
Newcastle's winners scored last. Two hits is a very small sample.
